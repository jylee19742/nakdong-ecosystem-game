# 낙동강 생태계 지킴이 탐험대

낙동강 생태계를 배우고 복원하는 교육용 온라인 보드게임입니다.

## 현재 상태

초기 저장소와 폴더 구조를 준비한 단계입니다. 게임 실행 기능과 여러 기기 간 실시간 동기화는 아직 구현하지 않았습니다.

## 개발 목표

- 탐험판과 생태계판 구현
- 상류·중류·하류·습지 구역과 구역별 미션카드
- 2~4명 참여자의 말 위치, 정답 처리, 이동 및 복원 조각 관리
- 출발 후 10문제 성공으로 마지막 생태지킴이 자격 획득 칸 도달 검증
- PC와 모바일 지원, 이후 여러 기기에서 함께하는 온라인 플레이

세부 규칙과 미션 내용은 원본 자료를 확인한 후 확정합니다.

## 폴더 구조

| 폴더 | 용도 |
| --- | --- |
| src/ | 게임 화면과 공통 코드 |
| src/game/ | 이동, 차례, 정답, 복원 규칙 |
| src/components/ | 보드, 카드, 말 등 화면 요소 |
| server/ | 향후 방 생성과 실시간 동기화 |
| public/assets/ | 보드와 카드 이미지·음원 |
| data/missions/ | 구역별 미션 데이터 |
| docs/ | 게임 규칙, 설계 및 개발 기록 |
| tests/ | 게임 규칙과 동작 검증 |

## 비공개 원칙

저장소는 Private으로 유지합니다. 소유자의 명시적 승인 없이 공개 전환, 외부 공개 배포, GitHub Pages 활성화, 외부 공유를 하지 않습니다. 비밀번호, API 키, 학생 개인정보는 커밋하지 않습니다.

## Codex 클라우드 연결

Codex에서 이 저장소를 선택하여 클라우드 환경을 만듭니다. 현재 의존성이나 빌드 명령은 없습니다. 기술 구성 확정 후 설치·실행·테스트 명령을 이 문서에 추가합니다. 작업 전 AGENTS.md를 확인하세요.
